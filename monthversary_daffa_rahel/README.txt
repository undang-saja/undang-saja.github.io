MONTHVERSARY — DAFFA & RAHEL

CARA MENJALANKAN
1. Ekstrak ZIP ini.
2. Buka folder monthversary_daffa_rahel.
3. Klik dua kali index.html, atau buka file tersebut menggunakan browser (Chrome, Edge, Firefox, Safari).
4. Website dengan animasi scroll-reveal, hati melayang, efek sparkle saat disentuh, dan transisi interaktif berjalan tanpa instalasi dan sudah responsif untuk HP maupun laptop.

PERSONALISASI
- Galeri: ketuk kotak foto untuk memilih gambar dari perangkat. Tombol Tambah bingkai foto menambah slot baru.
- Musik: pilih file audio dari perangkat, lalu tekan tombol play.
- Surat cinta, nama, dan tanggal jadian dapat diedit di index.html dengan editor teks.

CATATAN
Foto dan musik dipilih secara lokal di browser; file tidak diunggah ke server. Jika ingin membagikan website lewat tautan publik, unggah folder ini ke layanan hosting statis seperti GitHub Pages atau Netlify. Font online memakai Google Fonts; jika offline, font sistem akan digunakan.
